# Bonami Web | Nostalgic Disco Event & Interactive Audio Experience

Landing page Single Page Application (SPA) moderna desarrollada para un evento conceptual que rinde homenaje y rememora la mítica discoteca **Bonami** de Zona Sur.

---

## 🎧 Concepto & Experiencia Interactiva

La web combina la nostalgia de las noches icónicas de Bonami con una experiencia digital moderna y fluida:

* 🎛️ **Custom Audio Player "Vinyl Edition":** Reproductor de música dinámico, rápido y altamente estético con diseño de disco de vinilo giratorio y brazo/púa interactiva.
* 🎟️ **Call to Action para Tickets:** Sección directa enfocada en la venta y reserva de entradas para el evento retro.
* 🪩 **Quienes Somos:** Historia y espíritu que reviven la memoria de la clásica discoteca de Zona Sur.
* 📬 **Sección de Contacto:** Canal directo para consultas, reservas e información general.

---

## 🛠️ Tech Stack & Herramientas

* **Frontend Framework:** React 18 + Vite (para garantizar una reproducción continua y sin interrupciones)
* **Estilos & Animaciones:** Tailwind CSS (diseño responsive, estética retro-moderna y animaciones custom para el vinilo)
* **Audio Handling:** API de audio nativa optimizada para carga rápida de pistas
* **Control de Versiones:** Git / GitHub Workflow (`main` & `develop`)

---

## ✨ Características Técnicas

* ⚡ **SPA Ultrarrápida:** Carga instantánea de secciones sin recargas de página.
* 🎵 **Custom Player Component:** Estado y animaciones sincronizadas entre la reproducción de audio, la púa y el giro del vinilo.
* 📱 **Layout Mobile-First:** Adaptabilidad total del reproductor y las secciones en dispositivos móviles y escritorios.

---

## 💻 Desarrollo Local

Para clonar y probar el proyecto en tu máquina:

* Clonar repositorio: `git clone https://github.com/SebaGimenezOk/BonamiWeb.git`
* Entrar al directorio: `cd BonamiWeb`
* Instalar dependencias: `npm install`
* Iniciar servidor de desarrollo: `npm run dev`
* Compilar para producción: `npm run build`
